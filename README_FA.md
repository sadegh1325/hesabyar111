# راهنمای جامع سامانه حساب‌یار فروشگاه (مدیریت فروش و حساب مشتریان)

سامانه **حساب‌یار** یک اپلیکیشن فول‌استک (Full-Stack)، مدرن و امن برای جایگزینی کامل دفاتر کاغذی حساب‌وکتاب فروشگاه‌ها است. این سامانه با دیتابیس مرکزی مستقل، محاسبات دقیق مالی، خروجی‌های واقعی Excel و Word، قالب‌های اختصاصی چاپ فاکتور و رسید، و احراز هویت امن پیاده‌سازی شده است.

---

## ۱. مشخصات و فناوری‌های به‌کار رفته

- **فرانت‌اند:** React 19 + TypeScript + Tailwind CSS (راست‌چین RTL، تایپوگرافی وزیرمتن Vazirmatn، اعداد فارسی و فرمت تومان)
- **بک‌اند:** Node.js + Express REST API (مسیرهای سرور امن با کنترل نشست)
- **دیتابیس مرکزی:** SQLite با حالت پیشرفته WAL (Write-Ahead Logging)، یکپارچگی کلیدهای خارجی و تراکنش‌های اتمیک ACID
- **تولید اسناد:** کتابخانه رسمی `xlsx` برای فایل‌های اکسل ۸ شیته و `docx` برای صورت‌حساب رسمی Word
- **تقویم و تاریخ:** تقویم جلالی/شمسی بر پایه `jalaali-js`
- **امنیت:** هش رمزهای عبور با `bcrypt` و توکن‌های نشست ۳۰ روزه

---

## ۲. مشخصات حساب کاربری پیش‌فرض مدیر فروشگاه

در اولین اجرای برنامه، حساب مدیر به صورت خودکار ایجاد می‌شود:
- **نام کاربری:** `admin`
- **رمز عبور اولیه:** `admin123`

*(توجه: توصیه می‌شود پس از اولین ورود، از تب «تنظیمات و پشتیبان» رمز عبور خود را تغییر دهید).*

## ۳. نحوه راه‌اندازی و اجرای محلی (Local Development)

```bash
# ۱. نصب وابستگی‌های پروژه
npm install

# ۲. اجرای آزمون‌های خودکار مالی
npm test

# ۳. اجرای سرور توسعه (پورت ۳۰۰۰)
npm run dev
```

برنامه روی آدرس `http://localhost:3000` در دسترس خواهد بود.

---

## ۴. ساخت نسخه نهایی و استقرار روی سرور (Production Deployment)

```bash
# ساخت باندل فرانت‌اند
npm run build

# اجرای سرور عملیاتی
npm start
```

### تنظیم دسترسی از چند دستگاه (موبایل، تبلت، کامپیوتر) و HTTPS:
1. **استقرار ابری یا سرور اختصاصی (VPS/Cloud Run):** سرور برنامه را روی آدرس IP عمومی یا سرویس Cloud Run اجرا کنید.
2. **تنظیم دامنه و SSL/HTTPS:** با اتصال دامنه به همراه گواهی SSL رایگان (مانند Let's Encrypt یا Cloudflare)، آدرس به صورت `https://your-store-domain.com` در دسترس خواهد بود.
3. **دسترسی همزمان:** صاحب فروشگاه می‌تواند هم‌زمان از گوشی هوشمند، تبلت در مغازه یا لپ‌تاپ در منزل وارد شود و تمامی اطلاعات، بدهی‌ها و فاکتورها به صورت لحظه‌ای و یکسان در تمام دستگاه‌ها همگام هستند.

## ۵. بخش‌ها و امکانات برنامه

۱. **داشبورد مالی:**
   - نمایش فروش امروز و ماه جاری
   - مبالغ وصول‌شده امروز و کل ماه
   - مجموع مطالبات معوق و تعداد بدهکاران
   - نمودار مقایسه‌ای روند فروش روزانه با وصولی نقدی
   - فهرست پرفروش‌ترین کالاها و مشتریان با بیشترین خرید

۲. **ثبت فروش سریع (POS):**
   - جستجو یا تعریف سریع مشتری در فرم فروش (یا انتخاب «مشتری متفرقه»)
   - افزودن ردیف‌های کالا با مقدار اعشاری (کیلوگرم، متر، عدد و...)
   - اعمال تخفیف ردیف و تخفیف کلی فاکتور (مبلغی یا درصدی)
   - ثبت دریافت اولیه نقدی یا کارتخوان در زمان صدور
   - صدور فوری و چاپ فاکتور استاندارد با سربرگ و اطلاعات فروشگاه

۳. **پرونده مشتریان:**
   - پرونده مالی اختصاصی برای هر مشتری
   - تراز بدهکاری و بستانکاری
   - دانلود مستقیم گزارش رسمی Word (`.docx`) با جدول گردش حساب
   - چاپ صورت‌حساب مشتری

۴. **فاکتورها:**
   - فیلتر بر اساس وضعیت (تسویه، بخشی، پرداخت نشده، پیش‌نویس، ابطال)
   - چاپ استاندارد و بدون حاشیه فاکتور
   - ابطال فاکتور با ثبت دلیل و برگشت مبالغ به اعتبار مشتری

۵. **پرداخت‌ها و وصولی‌ها:**
   - ثبت دریافت‌های چندمرحله‌ای برای یک فاکتور
   - تخصیص یک فیش واریزی به چند فاکتور باز
   - ثبت پیش‌پرداخت به عنوان اعتبار مشتری
   - صدور و چاپ رسید رسمی پرداخت
   - استرداد وجه با ثبت ردپای حسابرسی (Audit Trail)

۶. **بدهکاران و مطالبات:**
   - مرتب‌سازی بر اساس بیشترین بدهی
   - ثبت سریع وجه بدون نیاز به رفتن به صفحات دیگر
   - خروجی اکسل ویژه بدهکاران

۷. **هزینه‌های فروشگاه:**
   - تفکیک هزینه‌ها (اجاره، قبوض، تعمیرات، حمل‌ونقل و...) مستقل از فروش

۸. **گزارش‌ها و خروجی‌ها:**
   - تولید فایل اکسل جامع (`.xlsx`) با ۸ شیت مجزا:
     1. مشتریان
     2. فاکتورها
     3. ردیف‌های اقلام
     4. پرداخت‌ها
     5. مانده حساب مشتریان
     6. گزارش روزانه و ماهانه
     7. هزینه‌ها
     8. خلاصه مالی

۹. **تنظیمات و پشتیبان‌گیری:**
   - ویرایش مشخصات فروشگاه، تلفن، آدرس و پیام‌های سربرگ فاکتور
   - دانلود فایل دیتابیس خام (`hesabyar.db`)
   - دانلود نسخه پشتیبان متنی (`JSON Dump`)
   - بازیابی سریع داده‌ها از روی فایل JSON
   - دکمه اجرای زنده آزمون‌های ۱۰گانه و مشاهده گزارش وضعیت
